ЗВУК ИГРЫ — какие файлы положить в эту папку

Форматы: m4a, mp3, wav, aac или caf. Имя файла — ровно как ниже (без пробелов), расширение любое из списка.
Всё необязательно: чего нет — того просто не слышно (синтезированный шум фонов убран).
Папка Audio попадает в сборку целиком; музыкальные файлы в git не коммитятся (.gitignore).

1. МУЗЫКА (играет по кругу, плавно сменяется)
   music_default   — общий трек, если для места нет своего (или EyesOnFire.mp3, как раньше)
   music_menu      — главное меню
   music_prologue  — пролог, дорога в Форкс
   music_biology   — гл. 1, кабинет биологии
   music_van       — гл. 3, парковка и фургон

   music_chase     — гл. 18, погоня

2. ФОНЫ (бесшовная петля 20–60 с)
   amb_rain       — дождь (класс, пролог, улицы)

   amb_forest     — лес днём: птицы, листва
   amb_crickets   — ночь, сверчки

   sfx_thunder      — далёкий гром
   sfx_thunderNear  — близкий удар грома
   sfx_skid         — визг шин (фургон на льду)
   sfx_impact       — удар металла (вмятина, столкновение)
   sfx_batCrack     — удар биты по мячу
