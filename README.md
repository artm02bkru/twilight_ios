# 🌙 СУМЕРКИ: Четыре главы

Фанатская мини-игра по книге «Сумерки» для iPad (и iPhone) на SwiftUI.
Четыре сцены книги — четыре разных управления одним пальцем.

| Глава | Сцена | Механика |
| --- | --- | --- |
| 3 | **Феномен** — парковка школы | **Коснуться** в момент, когда фургон войдёт в зону |
| 13 | **Признание** — тайный луг | **Вести пальцем**, уводя Эдварда из солнечных лучей |
| 17 | **Игра** — бейсбол в грозу | **Коснуться**, когда мяч в зоне; гром заглушает звук удара |
| 19 | **Прощание** — балетная студия | **Удерживать и отпускать**: вытянуть яд, не потеряв контроль |

## Как собрать в Xcode

1. Распакуйте папку `TwilightNight`.
2. Откройте **`TwilightNight.xcodeproj`** двойным щелчком.
3. Сверху выберите схему **TwilightNight** и симулятор iPad
   (например, *iPad Pro 11-inch (M4)*) либо подключённый iPad.
4. Нажмите **⌘R**.

Сторонних библиотек нет, ничего доустанавливать не нужно.

### Запуск на реальном iPad

В настоящем устройстве нужна подпись. В настройках таргета
(**TwilightNight → Signing & Capabilities**):

1. **Bundle Identifier** — замените `com.example.TwilightNight` на свой уникальный.
2. **Team** — выберите свою учётную запись Apple ID.

После этого ⌘R соберёт игру на iPad.

**Требования:** Xcode 15+, iOS / iPadOS 16.0+.

## Как играть

Три жизни на всю историю: ошибка в любой главе отнимает одну.
Рекорд сохраняется между запусками.

**Глава 3. Фургон.** Фургон Тайлера скользит по льду. На асфальте светится зона —
касайтесь экрана ровно в тот момент, когда фургон в неё войдёт. Точность по центру
зоны даёт больше очков. Промах — Белла не успела.

**Глава 13. Луг.** Облака расходятся, и по лугу едут солнечные столбы. Ведите пальцем
и держите Эдварда в тени: в тени на его коже вспыхивают алмазные искры и капают очки.
Шкала «СОЛНЦЕ ВЫДАЁТ» заполнится — минус жизнь.

**Глава 17. Игра.** Гром ходит волной — это видно по шкале с молнией. Бейте, когда мяч
в зоне: если в этот момент громкий гром, удар идеальный и приносит больше всего очков.
Тихий удар слышно на весь лес — три таких, и кочевники придут.

**Глава 19. Прощание.** Удерживайте палец — Эдвард вытягивает яд, но растёт жажда.
Отпускайте, чтобы жажда спала. Чем меньше яда осталось, тем быстрее он теряет контроль.

В конце — финал с итоговым званием: от «Человека» до «Бессмертной».

## Музыка

В игре играет **Paramore — I Caught Myself** (трек из саундтрека к фильму).
Файл лежит в проекте: `TwilightNight/Audio/ICaughtMyself.mp3`, 3:54, и попадает
в сборку как ресурс.

* Трек запускается сразу при открытии игры и играет **по кругу** без остановки.
* Появляется плавно (фейд ~1.8 с), чтобы не бить по ушам на старте.
* **Переключатель звука** есть в двух местах: строка «МУЗЫКА ВКЛЮЧЕНА / ВЫКЛЮЧЕНА»
  в главном меню и круглая кнопка с динамиком в правом верхнем углу во время игры.
* Выбор запоминается между запусками (`UserDefaults`, ключ `twilight.music.muted`).
* Аудиосессия — `.ambient`: игра **уважает переключатель «без звука»** на iPad и
  не глушит музыку из других приложений. Фоновое воспроизведение не включено —
  при сворачивании игры музыка замолкает, при возврате продолжается.

### Как поставить свою музыку

1. Положите файл в `TwilightNight/Audio/`.
2. В Xcode перетащите его в группу **Audio** и убедитесь, что он отмечен
   в *Target Membership → TwilightNight*.
3. Если имя файла другое — поменяйте `resourceName` в `Soundtrack.swift`.
4. Если формат не MP3 (например, m4a) — поменяйте там же `resourceExtension`.

Если файла в сборке не окажется, игра просто запустится без музыки и напишет
предупреждение в консоль — падения не будет.

> ⚠️ Трек защищён авторским правом. Для себя собирать можно, но **нельзя
> выкладывать сборку с ним** в App Store, на GitHub или куда-либо ещё —
> для публикации нужна музыка с подходящей лицензией.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `TwilightNightApp.swift` | Точка входа, тёмная тема, скрытый статус-бар |
| `RootView.swift` | Сборка экрана, жест, переключение фаз |
| `HudView.swift` | Очки, жизни, полоса главы и приборы (гром, жажда, солнце) |
| `Overlays.swift` | Меню, карточка главы, пауза, итоги, финал |
| `GameEngine.swift` | Дирижёр: ведёт главы, считает очки и жизни, раздаёт ввод сценам |
| `GameCore.swift` | Общие типы: кадр, ввод, результат сцены, фазы |
| `BookContent.swift` | Тексты глав, правила, звания |
| `SceneVan.swift` | Глава 3 — тайминг-тап |
| `SceneMeadow.swift` | Глава 13 — лучи и тень |
| `SceneBaseball.swift` | Глава 17 — гром и удары |
| `SceneStudio.swift` | Глава 19 — яд против жажды |
| `SceneCanvas.swift` | Отрисовка активной сцены в `Canvas` |
| `Backdrops.swift` | Четыре фона: парковка, луг, поле в грозу, студия |
| `Sprites.swift` | Доступ к PNG-спрайтам персонажей |
| `DisplayLinkDriver.swift` | Игровой цикл на `CADisplayLink`, честный delta-time |
| `Soundtrack.swift` | Фоновая музыка: зацикливание, фейды, переключатель звука |
| `Audio/ICaughtMyself.mp3` | Трек Paramore — I Caught Myself |
| `tools/make_sprites.py` | Генератор спрайтов (Python + Pillow) — не участвует в сборке |

## Персонажи

Персонажи — не эмодзи и не палочки: это сгенерированные спрайты 400×900
(Белла, Эдвард, Алиса, Розали, Джаспер, Эмметт, Джеймс) плюс позы
(удар битой, замах питчера, вытянутая рука, фургон, крупный план раны).

Скрипт `tools/make_sprites.py` рисует их параметрически: анатомические пропорции
(~7.4 головы), мягкая светотень градиентами, объёмные конечности, черты лица,
пряди волос. Перегенерировать спрайты можно так:

```bash
python3 tools/make_sprites.py sprites_out
```

Там же сохранится контактный лист `_sheet.png` со всеми персонажами.

## Что можно покрутить

* Сложность фургона — `VanScene.currentSpeed` и `currentHalf`.
* Сколько держится луг — `MeadowScene.duration`.
* Частота и ширина солнечных лучей — блок спавна в `MeadowScene.update`.
* Цикл грома — `thunderPhase += dt * 1.75` в `SceneBaseball.update`.
* Баланс финала — `StudioScene.venomRate` и `thirstRate`.
* Любые тексты — `BookContent.swift`.
* Громкость музыки — `SoundtrackPlayer.normalVolume`.
