# Ключи «Сумерки»: 1 ключ — 1 устройство

Сервер живёт внутри Telegram-бота @twilight_xbot: бот выдаёт ключи, а игра при первом запуске
отправляет ключ на `POST /activate` и получает подписанную лицензию.

## Как это работает
1. При первом запуске игра создаёт случайный ID устройства и хранит его в Keychain
   (только на этом iPad, переживает переустановку игры, не переносится через iCloud).
2. Игрок вводит ключ → игра шлёт `{"key", "device"}` на сервер.
3. Сервер:
   * ключ свободен → привязывает к устройству и отдаёт лицензию, подписанную приватным ключом;
   * ключ уже на этом устройстве → снова отдаёт лицензию (переустановка);
   * ключ на другом устройстве → `409` «уже активирован на другом устройстве»;
   * нет ключа → `404`, отозван → `403`.
4. Игра проверяет подпись встроенным публичным ключом и ID устройства, сохраняет лицензию
   в Keychain и дальше работает **без интернета**. Скопировать лицензию на другой iPad нельзя —
   там другой ID.

## Установка
```bash
pip install -r requirements.txt
python keygen.py          # PUBLIC → в игру, PRIVATE → на сервер
```
Переменные окружения сервера (задаются в настройках хостинга, не в коде):
* `LICENSE_PRIVATE_KEY` — PRIVATE из keygen.py (никому не показывать, не коммитить);
* `BOT_TOKEN` — токен бота от @BotFather;
* `ADMIN_IDS` — ваш Telegram ID (узнать: @userinfobot), через запятую, если админов несколько;
* `PORT` — порт (по умолчанию 8080), `DB_PATH` — файл базы (по умолчанию `licenses.db`).

Запуск: `python license_server.py` — одновременно поднимает HTTP `/activate` и бота.
Нужен адрес с HTTPS (VPS + домен, Render, Railway, Fly.io и т. п.) — iOS не пустит на голый http.
Если у бота уже есть свой код — можно перенести функции `activate`, `make_keys`, `sign_license`
и команды в него; формат ответа менять нельзя.

## Подключить к игре
В `TwilightNight/Core/License.swift`:
```swift
static let activationURL = URL(string: "https://ВАШ-ДОМЕН/activate")!
static let publicKeyBase64 = "PUBLIC из keygen.py"
```
Пока `publicKeyBase64` пустой, экран ключа не показывается — игра открыта.

## Команды бота (только для ADMIN_IDS)
* `/newkeys 10` — создать 10 ключей вида `TW-ABCD-EFGH-JKLM`
* `/keys` — статистика и последние ключи
* `/info TW-...` — к какому устройству привязан, когда
* `/reset TW-...` — сбросить привязку (игрок сменил iPad)
* `/revoke TW-...` / `/unrevoke TW-...` — отозвать / вернуть ключ

## Ограничения
* Только для распространения вне App Store (TestFlight, Ad Hoc, AltStore, enterprise) —
  App Store требует встроенные покупки вместо внешних ключей (правило 3.1.1).
* Сброс iPad до заводских настроек меняет ID — такому игроку делается `/reset` его ключа.
